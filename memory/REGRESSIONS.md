# Régressions

## Format

Chaque régression doit indiquer :

- identifiant ;
- symptôme ;
- cause ;
- fichiers concernés ;
- test ajouté ;
- correction ;
- prévention.

## Registre

Aucune régression nouvelle enregistrée dans le Project OS.

Les défauts historiques du site et des visuels restent documentés dans `_DOCS/` et `_JOURNAL/`.
