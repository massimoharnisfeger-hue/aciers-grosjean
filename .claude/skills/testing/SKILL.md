# Testing

## WHEN TO USE

Après toute modification et avant tout verdict `DONE`.

## STEPS

1. identifier les critères d'acceptation ;
2. exécuter les tests ciblés ;
3. exécuter la régression pertinente ;
4. vérifier les erreurs et cas limites ;
5. produire les logs et les tests non exécutés.

## FAILURE

Un test critique échoué produit `STOP` ou `FIX`.

## OUTPUT

Verdict `PASS`, `FIX` ou `ESCALATE` avec preuves.
