# Project Audit

## WHEN TO USE

Pour établir ou réviser l'état réel du projet.

## STEPS

1. vérifier Git ;
2. lire les règles applicables ;
3. inventorier architecture, dépendances et données ;
4. rechercher tests, CI, hooks et secrets ;
5. comparer besoin, cible et existant ;
6. produire les écarts et les preuves.

## OUTPUT

Rapport factuel avec chemins précis, risques et inconnues.
