# Règles fondamentales

1. Le dossier métier est la référence fonctionnelle.
2. L'architecture V3 est la référence de gouvernance.
3. Le dépôt réel prime sur une affirmation non vérifiée.
4. Explorer les règles, l'état et les dépendances avant toute modification.
5. Ne jamais inventer une règle, une donnée, une source ou une décision.
6. Tout changement doit avoir un périmètre, un impact, des tests et un rollback raisonnable.
7. Les opérations financières, de sécurité, de migration, destructives ou de production exigent un human gate.
8. Une compilation réussie ne suffit pas pour déclarer une tâche terminée.
