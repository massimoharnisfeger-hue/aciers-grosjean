LANCER LE SITE SUR VOTRE ORDINATEUR
===================================

Il faut Node.js installé (https://nodejs.org, version LTS).

1. Ouvrez un terminal dans ce dossier.

2. Installez les dépendances, une seule fois :

       npm install

3. Lancez le site :

       npm run dev

4. Ouvrez http://localhost:3000 dans votre navigateur.

Pour arrêter : Ctrl+C dans le terminal.


POUR VOIR LA VERSION DE PRODUCTION (les 638 pages générées)
-----------------------------------------------------------

       npm run build
       npm start

Puis http://localhost:3000. C'est plus long à démarrer mais c'est
exactement ce qui serait publié.


REGÉNÉRER LE CATALOGUE
----------------------

Le catalogue (lib/catalogue.ts) est généré depuis le CSV d'inventaire.
Pour le reconstruire après modification du CSV :

       python3 scripts/generer-catalogue.py chemin/vers/inventaire.csv

Idem pour le logo, depuis le PDF de la charte :

       python3 scripts/extraire-logo.py chemin/vers/charte.pdf
