# Critères d'acceptation

Chaque fonctionnalité doit préciser :

- objectif ;
- acteur ;
- préconditions ;
- action ;
- résultat attendu ;
- cas limites ;
- cas d'erreur ;
- règles métier ;
- preuves attendues.

La fonctionnalité n'est pas `DONE` sans tests, revue, régression, documentation et validation adaptées au risque.
